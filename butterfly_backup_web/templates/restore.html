Restore Options:
  • Computer - Target computer hostname or IP address for restore
  • User - SSH username for connecting to the target computer
  • Port - SSH port number (default: 22)
  • Backup ID - Unique identifier of the backup to restore
  • Root Directory - Destination path for restored data
  • Type - Restore type: full or incremental
  • Compression - Handle compressed backup data
  • Checksum - Verify data integrity during restore
  • ACL - Restore Access Control Lists
