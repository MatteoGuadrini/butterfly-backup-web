Backup Options:
  • Computer - Target computer hostname or IP address for backup
  • User - SSH username for connecting to the target computer
  • Port - SSH port number (default: 22)
  • Mode - Backup mode: ssh, local, or rsync
  • Data - Source data path to backup
  • Type - Backup type: full or incremental
  • Retention - Set retention policy by days or number of backups
  • Compression - Enable data compression during backup
  • Checksum - Verify data integrity using checksums
  • ACL - Preserve Access Control Lists during backup
